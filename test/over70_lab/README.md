# 1080P >70 FPS 实机探索（独立项目）

独立于 `../stable_69p5_1080p`，新编译、日志和原始样本全部写在本项目内部。

目标：
1. 确认是否存在 **27 MHz、1920×1080，实测 PTS 与VI均超过70FPS** 的真实采集档位。
2. **MIPI CRC、Hdr、WordCount、FIFO应为0**；新测试中任何增长都立即终止，保存现场。
3. 原NV21质量顶部行逐帧抽样+格式长度检查，不能用裁掉问题行、插帧或编码伪造。
4. 温度只用于过程监测，不能单凭某一次SoC温度推断sensor损坏。

边界：新的传感器HTS白名单先从1180向1165小步探索，已知1150无法采集。可能无法达标；GC4653手册不建议随意修改HTS，这些仅是研究实验而非可交付生产模式。

独立程序：`source/`，测试脚本：`run_lab.py`，实验输出：`results/`。

不加载内核模块，不写板端原摄像头目录，板端只用临时 /tmp 和相机互斥锁；若板端有预览进程则拒绝抢占。原69.5 FPS方案始终可用。
