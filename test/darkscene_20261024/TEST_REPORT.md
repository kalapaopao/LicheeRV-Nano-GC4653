# 摘盖后真实暗场验证

后续新背景沿用BLC256＋自动白平衡的结果见[新背景验证报告](NEW_BACKGROUND_27133_3269.md)，不应将本页较早的背景照片误认为最新一次采样。

日期：2026-10-24。用户表示已取下镜头盖、转到暗处后执行。目标：验证BLC256在真实暗场是否仍能改善红紫底色，并观察是否存在剩余偏色/细节问题。

## 结论

- **已验证改善：**同为80档、5000us、1倍AE增益、同一固定WB及CCM，原BLC252图像有明显红紫底色；BLC256图像中的大面积红紫明显减弱。
- **不是全部画质验收：**BLC256配固定参考WB仍可见偏绿区域，画面整体非常暗；改回原自动WB后全图暗像素均值更接近平衡，但不等于完成色准标定。
- 图片中无法明确辨认绿色灯塔装置，缺少目标可见性/灰卡参照，不能证明装置暗部细节或模型识别采集质量合格。不能据此宣称完全不压黑细节或所有环境下无偏色。
- 未改正式程序或YAML；本轮只是独立测试。当前正式入口仍加载原BLC，重新启动仍可能偏红。

## 后续建议和验收边界

本轮支持在当前5000us/1倍增益场景把BLC256作为修正候选，而不是为消除偏红退回60FPS。正式接入前应明确配置范围、保留原BLC回退开关并验证目标细节。

请让完整灯塔装置及绿色灯进入画面，使用灰卡/已知中性色参考，验证白平衡、主体轮廓、绿色灯饱和程度与噪声。若5000us/1倍增益下主体仍不可辨，需单独改善曝光/照明；不能用错误黑电平抬亮底色来代替真实信号，也不能从本次均值推断训练数据已经合格。
